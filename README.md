# Saittoo.ink

Portfólio bilíngue (português/inglês) da tatuadora Camila Saito, em Echizen, Fukui, Japão.

## Protótipo inicial

- Página responsiva com identidade escura e detalhes vermelhos
- Seções: início, portfólio, sobre e contato
- Filtros Fine Line / Blackwork
- Alternância PT / EN
- Contato pelo [Instagram](https://www.instagram.com/saittoo.ink/)

## Como testar

Abra `index.html` no navegador. As imagens da galeria são espaços reservados para as fotos originais. A logo original e o layout completo do pacote ZIP anterior ainda precisam ser integrados a esta versão do repositório.

## Publicação

O repositório está privado. Para publicar no GitHub Pages, será necessário configurar o Pages e verificar os requisitos de visibilidade da conta.
