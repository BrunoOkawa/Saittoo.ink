# Saittoo.ink

Site/portfólio de Camila Saito, tatuadora em Echizen, Fukui, Japão.

O projeto usa a identidade oficial preta, branca e vermelha, com detalhes inspirados em respingos de tinta. O conteúdo é bilíngue (português/inglês).

## Abrir o site

Visite **https://brunookawa.github.io/Saittoo.ink/** após o GitHub Pages concluir a publicação.

Também pode abrir `index.html` localmente; não há bibliotecas, servidor ou ferramentas de compilação obrigatórias.

## Recursos

- Galeria de nove trabalhos reais, com filtros por estilo.
- Lightbox para ampliar as fotografias.
- Alternância entre português e inglês.
- Fotografia e apresentação da artista.
- Links de contato pelo Instagram `@saittoo.ink`.
- Layout responsivo, HTML semântico e imagens otimizadas em WebP.

## Conteúdo e direitos

A logo definitiva e as fotografias foram fornecidas para o projeto. Confirme a autorização de exibição das fotografias de clientes antes de ampliar a divulgação do site.

Os estilos atribuídos às fotografias são uma primeira classificação editorial, e podem ser alterados com a artista.
